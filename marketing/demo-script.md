# Demo Script

1. Log in with the manager account.
2. Open Dashboard and explain inventory value, units left, gains, low stock, expiry, and security alerts.
3. Open Capture and add a medicine by barcode or generated stock code.
4. Select a supplier and show saved email/phone auto-fill.
5. Open Sales and record a sale.
6. Select a controlled medicine and show the doctor report requirement.
7. Open Reports and show expired/expiring medication drill-down.
8. Open Security and show cash drawer check, stock count adjustment, and audit trail.
9. Download inventory and security reports.
