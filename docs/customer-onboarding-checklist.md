# Medholic Pharmacy Customer Onboarding Checklist

Use this after a pharmacy agrees to proceed.

## Customer Information

- Pharmacy name:
- Owner or manager name:
- Contact email:
- Phone number:
- Location:
- Number of branches:
- Chosen package: Starter / Standard / Premium / White-label

## Setup Information To Collect

- Pharmacy logo if custom branding is needed.
- Staff names and roles.
- Opening stock list.
- Medicine names, categories, quantities, cost prices, selling prices, and expiry dates.
- Supplier names, phone numbers, and email addresses.
- Preferred low-stock alert levels.
- Payment methods used by the pharmacy.

## Setup Tasks

- Create manager login privately.
- Add staff roles.
- Add medicine inventory.
- Add supplier contacts.
- Test sales entry.
- Test low-stock alert.
- Test expiry report.
- Test download reports.
- Confirm backup setup.

## Training Tasks

- Show how to capture stock.
- Show how to record sales.
- Show how to check inventory left.
- Show how to view expiry reports.
- Show how to download reports.
- Show how to use the Security section.
- Show how to sign out safely.

## Go-Live Checklist

- Customer confirms login works.
- Customer confirms inventory is correct.
- Customer confirms staff understand their roles.
- Customer confirms official support contact.
- Customer confirms first backup/report download.
