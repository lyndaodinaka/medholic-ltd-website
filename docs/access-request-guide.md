# Medholic Pharmacy Access Request Guide

The login page includes **Request access as buyer or investor**.

## What Visitors Can Do

On the sign-in page, a buyer or investor can enter:

- Full name
- Email
- Buyer or Investor
- Message

When they submit, the app opens an email addressed to:

```text
nwaekpelynda1994@gmail.com
```

On Railway, the request is also saved on the server.

## How You View Requests

1. Log in as manager.
2. Open **Security**.
3. Click **View Access Requests**.
4. Click **Refresh**.
5. Use **Reply** to email the person back.
6. Use **Download CSV** to save the request list.

## Important

If the app is opened as a local file, the request opens an email but is not saved to the Railway database. Saved access requests work after the app is deployed on Railway.
