# Medholic Pharmacy Revenue Plan

## Best Income Model

Use Medholic Pharmacy as a subscription product, not only a one-time app sale.

## Recommended Packages

### Starter

For one small pharmacy or medicine store.

- Inventory capture.
- Sales records.
- Expiry alerts.
- Low-stock alerts.
- Basic reports.

### Standard

For busy pharmacies that need stronger daily control.

- Everything in Starter.
- Staff roles.
- Supplier ordering.
- Downloadable reports.
- Security tracing.
- Cash and stock adjustment records.

### Premium

For branches, clinics, or buyers that need setup support.

- Everything in Standard.
- Branch setup.
- Custom branding.
- Training.
- Priority support.
- Backup and restore support.

## Extra Ways To Earn

- One-time setup fee.
- Data entry service for medicine lists and suppliers.
- Staff training.
- Monthly support package.
- Custom branded/white-label version.
- Per-branch fee.
- Investor or buyer licensing.

## Lead Tracking Workflow

Use the Security section to view demo, pricing, buyer, investor, setup, and white-label requests.

Move each lead through:

```text
New -> Contacted -> Demo booked -> Quoted -> Won
```

Use **Lost** only when the person is not moving forward.

When a lead becomes **Won**, use:

- `docs/won-lead-next-steps.md`
- `docs/customer-onboarding-checklist.md`
- `docs/invoice-template.md`
