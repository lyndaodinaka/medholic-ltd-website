# Medholic Pharmacy Final Handoff Notes

This is the final guide for what to do after receiving the latest Medholic Pharmacy package.

## Latest Package To Upload

Upload this package:

```text
MedholicPharmacy-FINAL-LYNDA-CHIDI-PAGES.zip
```

Do not upload old zip files into GitHub. Open the latest zip and upload the contents inside it.

- Pharmacy inventory tracking.
- Barcode/manual/generated stock-code capture.
- Medication catalogue with function, dose guidance, and side effects.
- Quantity received, quantity sold, and quantity left.
- Low-stock alerts.
- Expiry alerts.
- Sales and gain tracking.
- Employee roster.
- Supplier phone and email storage.
- Reorder reports and purchase order downloads.
- Controlled/opioid medicine doctor report warning.
- Security audit trail.
- Cash drawer checks.
- Stock adjustment tracing.
- Private landing page and Medholic overview page.
- Printable Medholic flyer.
- Mobile-install preparation and Play Store guide.

## Railway Variables To Keep Private

Set these only in Railway Variables:

```text
ADMIN_EMAIL=your private manager email
ADMIN_PASSWORD=your private manager password
ADMIN_NAME=Lynda Chidi
```

Never write the manager password on public pages, GitHub, flyers, screenshots, or Play Store text.

## Final Upload Steps

1. Open the latest zip file.
2. Upload the contents to GitHub.
3. Wait for Railway to redeploy.
4. Open the live domain.
5. Log in as manager.
6. Test inventory, sales, reports, security, and backup download.
7. Open the marketing page.
8. Confirm the user label shows `Lynda Chidi - Manager`.

## Best Daily Workflow

1. Add new stock through Capture.
2. Record sales from the Sales section.
3. Check low-stock and expiry reports.
4. Use Security for cash checks, stock adjustments, and audit review.
5. Download backups and reports regularly.
